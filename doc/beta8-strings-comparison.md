# Beta.8 — сводная таблица переводов: было → предложено

## Принятое решение — текущий этап интеграции

Все предложенные переводы согласованы пользователем, включая уточнённую группу.
258 строк EN/RU внесены в assets; это подготовка ресурсов, **не готовая beta.8**.
Новые функции ещё не доступны без завершения runtime merge.

Для кнопок использовать **позиционную модель upstream beta.8**: held(),
назначения одинаковых действий, none, частичные назначения и отображение
настроек — из базовой версии. От форка оставить только Libra 2 / Qt5 landscape
correction в определении поворота. Старый actionRotation убрать при интеграции,
не применять его поверх held(). Это новое решение заменяет прежнее требование
сохранять physical-action семантику для обоих-next/none.

Если механизмы дублируют друг друга (standby при открытии, notes и т.п.),
брать цельную реализацию upstream. Если изменены отдельные пункты общей функции,
делать контекстное слияние с сохранением согласованных fork-отличий. Текущая
runtime-база c4b8c1e не заменена пробным merge; бинарник beta.8 пока не выпущен.
Подробности незавершённой интеграции — в FB2_FORK_PLAN.md.

Старый перевод взят из **текущего форка**, `assets/ru.strings` на `d774693`,
а не из upstream beta.7: у upstream нет нашей русской локализации.
Новый столбец — актуализированный proposal, **не применённый runtime-перевод**.
Уточнения и статусы согласования: [beta8-context-review.md](beta8-context-review.md).

отдельным открытым дефектом и не считается исправленным при переносе.

## 4. Новые upstream-ключи — EN и предложенный русский

Знак «—» означает: **именно этого ключа нет в старом RU**. В ряде мест есть
связанные старые элементы интерфейса — они указаны для ориентира, но не объявлены
автоматически переименованными ключами. В каждом подразделе приведены все строки,
без исключения коротких подписей или платформенных сообщений.

Основная группа согласована пользователем. Уточняемые строки sleep.letter_*,
sleep.design_pill, navigation.annotate/annotations, stats.page_turn/page_turns,
kosync.from/to остаются на повторном рассмотрении.

## 5. Правила согласования и применения

- В этой итерации не изменены `assets/en.strings` или `assets/ru.strings`.
- Первый proposal доступен в Git на 3ab829e; текущие таблицы обновлены по решению пользователя и контекстной проверке.
- Пользователь согласовал основные строки; повторного решения ждёт только уточнённая группа, перечисленная в beta8-context-review.md.
- Решения по старым строкам согласованы; runtime assets будут изменены при интеграции, не в этом отчёте.
- `%1`, `%2`, `%3`, пути, кавычки и переносы сохранять с учётом фактического вызывающего кода.
- Русские множественные формы проверять через существующий CLDR helper (one/few/many), а не по английским ключам.
- Короткие и длинные подписи проверять на Kobo; число символов не доказывает отсутствие обрезки.
