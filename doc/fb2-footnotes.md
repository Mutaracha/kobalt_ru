# Нижние сноски EPUB / FB2

Работа завершена по решению пользователя: индексы работают верно, текущие
отступы сохраняются. Дальнейшая доработка пагинации и зазоров не запланирована.
Это приёмка текущего поведения, не заявление об отдельном исправлении общего
алгоритма переноса ссылок и сносок.

## Текущий механизм

- Общая настройка `inpage_footnotes` из upstream beta.8; по умолчанию выключена.
- Старый Boolean `fb2_inpage_footnotes` переносится только при отсутствии
  canonical Boolean; явный canonical выбор имеет приоритет.
- EPUB использует механизм beta.8. Для FB2 поддержаны `notes` / `comments`.
- Числовые FB2 title идут вместе с началом текста через нативный `run-in`;
  номер в нижней сноске надстрочный. Исходный текст, скобки и IDs сохраняются.
- Длинные примечания могут продолжаться на следующих страницах.
- Позиции, ссылки, выделения и пагинация используют общий layout; рисуемых
  отдельно смещений ради отступов нет.

Парсерный FB2 cache marker — `:fb2-v8:`. Инвалидация касается только производного
кэша, не книг, закладок или настроек. Контракт: [storage](storage.md).
Focused native FB2/UI и Kobo Qt5 прошли в
[CI44075570386](https://github.com/Mutaracha/kobalt_ru/actions/runs/44075570386).
Portable regressions сохранены; старые аналитические отчёты и снимки удалены
из текущего дерева и доступны в истории Git.
