# Архив материалов

История, не действующие инструкции и не очередь. Старые pending/accepted/next
действуют только в контексте указанной сборки; не переносить их в текущий план.

- `pre-beta10/doc/` — отчёты, проверки и инструкции для beta9 и старше.
- `mixed-history/` — прежние накопительные план/решения/карта, содержащие несколько
  поколений, в том числе beta10. Сохранены отдельно от коротких действующих документов.
- [Манифест переносов](material-moves.json) — старый/новый путь, причина, исходный SHA256.
  В Markdown относительные ссылки могут быть перенастроены; raw bytes неизменны.
- [Сырые данные старых сборок](../../test%20%26%20diagnostic/archive/pre-beta10/README.md).

Актуальные источники: [план](../../FB2_FORK_PLAN.md), [решения](../fork-decisions.md),
[журнал beta10](../reports/patch-series/README.md), [проверки](../validation/beta10-device.md).
Материалы не удалены; бинарные ZIP/шрифты/книги/снимки не перепакованы.

Проверка консолидации из корня: `python3 doc/tools/check-materials.py`.
Итоговая запись: [отчёт](../reports/materials-consolidation.md).
