# Kobalt kobalt_ru — текущая beta10-серия

Нативный FB2, русский интерфейс/CLDR/переносы, comics и согласованное оформление
поверх upstream beta10. [Актуальный пакет и очередь](../FB2_FORK_PLAN.md),
[журнал проверок](reports/patch-series/README.md). Общая инструкция: [Reader](reader.md).

## Установка

Текущий проверенный пакет — artifact `Kobalt-ru-beta10-series-qt5` для Kobo Qt5,
ссылка на точную сборку в плане. Docs-only SHA не создаёт новый installer.
Распаковать внешний Actions artifact, затем внутренний `Kobalt-ru-beta10-series-qt5.zip`.
При закрытом Kobalt сохранить профиль целиком. По USB скопировать `.adds`, затем
`.kobo` в корень устройства с объединением папок, безопасно извлечь и дождаться
установки. Не удалять книги/профиль/кэш ради обновления. Не откатывать старую
программу поверх мигрированного профиля: нужен соответствующий backup.

## Язык и оформление

Настройки → Отладка → первый пункт «Язык интерфейса»: English/Русский/Automatic.
Выбор сохраняется, применяется после перезапуска; входа через About нет.
Автоматический RU учитывает ExtraLocales/CurrentLocale; C/POSIX не навязывает язык,
английский остаётся fallback. Locale не меняет глобальные настройки Nickel.
RU serif — Monotype Corsiva, playful handwriting — Caveat вместо Kalam;
classic Sans и явно выбранные шрифты не подменяются. В строке «Закрыть Kobalt»
слово Kobalt — Instrument Serif. Полное новое семейство Corsiva ещё не подключено.

## FB2 и Hybrid

Обычный `.fb2` UTF-8/windows-1251 открывается нативно, без конвертации в EPUB.
Поддерживаются содержание, notes/comments, картинки, обложка, стихи и сохранённые
позиции. Общие нижние сноски по умолчанию выключены; тап по ссылке использует
доступный preview. Числовые заголовки примечаний — native run-in.

Accurate раскладывает всю книгу перед чтением. Экспериментальный Hybrid при первом
открытии новой книги без кэша раскладывает начальный участок и готовит полную модель
в фоне. До full-ready общий total не выдаётся за точный. Переход вне участка может
потребовать полного fallback с паузой. Saved-position/cache открытия используют полный
документ. Это не секционная модель для ускорения произвольной середины FB2.

Кэш производный: его идентичность не заменяет позиции/закладки. Prefix не записывается
как полный документ; после готовности сохраняется full model. Закрытие раньше
готовности не гарантирует новый full cache. Cache hit не всегда означает совместимую
готовую вёрстку. Пользовательские данные автоматически ради замеров не удалять.

## Комиксы и диагностика

Comics per-book default off: aspect-fit, временное игнорирование полей/chrome без
сброса пользовательских значений. В landscape учитываются spreads/standalone center.

В Отладке можно включать/выключать подробную запись логов с сохранением состояния.
В текущем пакете forced verbose выключен; OFF сохраняет компактный warning/error log.
Для разбора проблемы включить подробные логи до воспроизведения, отметить время и
source commit, экспортировать архив. Данные: [каталог](../test%20%26%20diagnostic/README.md).

Исторические пакеты/инструкции beta9 и старше — [архив](archive/README.md),
они не являются рекомендуемыми сборками. Текущие ограничения — [решения](fork-decisions.md).
