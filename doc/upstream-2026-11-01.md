## Важное перед установкой

Upstream теперь использует SQLite schema 3 и новые механизмы восстановления повреждённых/неподдерживаемых данных с переносом оригиналов в backups/. Перед испытанием скопируйте весь профиль `.adds/kobalt/` на компьютер. Возврат к прежней сборке со schema 2 без восстановления соответствующей резервной копии не считается безопасным. Это изменение upstream, а не функция очистки кэша форка. См. [контракт хранения](storage.md).

## Проверки и ограничения

Локально пройдены `platforms/ci/test.sh`, parity en/ru, генерация обеих таблиц со сканированием src и `git diff --check`. Полная сборка Kobo Qt5 проверяется push-triggered workflow; результат следует смотреть по SHA merge-коммита. В Linux Arena нет Qt SDK/контейнерного движка: native mac-tests, Kobo UI и Android здесь не запускались. Снимки в `screenshots/kobo-ru/updated/` подтверждают предыдущие доработки, а не эту интеграцию. После успешной сборки необходима проверка EPUB/FB2, прогресса и сносок на Kobo.

## Действия владельца репозитория

Синхронизация main в интерфейсе GitHub обновляет лишь main форка; сама по себе она не объединяет upstream с рабочей веткой. Для этой интеграции ручных действий владельца не требуется. После проверок рабочую ветку можно отдельно влить в main по явному решению владельца. Не используйте принудительное отбрасывание fork-коммитов при синхронизации.
