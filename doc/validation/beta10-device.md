Сохранить весь профиль при закрытом Kobalt. Не ставить старый бинарник поверх
мигрированного профиля и не очищать пользовательские данные ради замера.

## Следующий короткий прогон

1. Проверить source commit eafb6161. RU: «Закрыть» — Monotype Corsiva,
   Kobalt в той же строке — Instrument Serif regular. EN — Instrument Serif для бренда.
2. Debug → подробные логи: включить, перезапустить, проверить сохранение состояния;
   выключить и повторить. OFF — компактные warning/error логи, не forced verbose.
   Перед измерениями вернуть ON. Язык интерфейса — первый Debug пункт.
3. Две реальные FB2, Accurate и Hybrid: дождаться полного count, закрыть в систему,
   перезагрузить, открыть. Записать time-to-readable-text, местное время/порядок,
   правильность позиции и счётчика. Сопоставить cache-save и disk hit в логе.
4. Если disk hit медленный — сохранить отдельный архив, не повторять до красивого
   результата. model_parse/paginate/load и session reading — разные границы.
5. Hybrid: первые две страницы до полного count не показывают prefix total как полный;
   после full-ready/footer и reopen значения корректны. Этот дефект уже исправлен
   и принят пользователем на 7f47164; здесь только проверка отсутствия регрессии.
6. Для расширенного покрытия: notes туда/назад, глава/процентный переход, граница
   prefix/full, reflow/ориентация, close/USB/cancel во время фона. Не считать
   ранее выполненный проход chapters/notes доказательством всех этих сценариев.

Cold A/B требует отдельных новых fingerprint без сохранённой позиции. Warm disk
после перезагрузки не смешивать с retained close/open в одном процессе. Для cold
достаточно согласованных тестовых копий, не удалять оригинальные пользовательские данные.
Допустима пауза безопасного whole-book fallback, недопустимы пропуск/дублирование
текста, неверный якорь или ложный точный total. Не ждать бесконечно при зависании.

Результаты фиксировать раздельно: CI, cold speed, disk lifecycle, count/adoption,
UI, стресс/lifetime. Логи: [каталог данных](../../test%20%26%20diagnostic/README.md).
Исторические beta9 проверки не заменяют beta10. EPUB counter recheck и freeze
остаются отдельными пунктами плана, не разрешением менять upstream алгоритмы.
