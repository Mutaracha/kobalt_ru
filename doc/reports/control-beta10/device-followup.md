## Какие прежние изменения связаны с дефектами

### Подпись: подтверждённая прежняя правка ca50dd3

`src/ui/controls/buttons.cpp`, ветка `iconAboveLabel`:

- reference ink-box `H` определяет прежнюю общую базовую линию группы;
- фактический `interfaceInkBounds(text(), font())` определяет область подписи;
- Y сдвигается на `labelInk.top() - commonInk.top()`, высота = `labelInk.height()`.

Это исправление Cyrillic ink-box из `ca50dd358386e9fccc5122b464f74003caa51e75`.
Первый контроль намеренно его не содержал: требовалось отдельное согласование
рисования. Теперь пользователь явно попросил добавить. Перенесена **только**
эта геометрия текста, не fork icon painting/state, не языковой dialog и не UI.

### Батарея: не переносить старый formatter целиком

В нашем fork `ca50dd3` `BatteryIndicator::setStatus()` использует
`strings::get("common.percent").arg(percent)`; обе таблицы содержат `%1%`.
Прямой числовой аргумент + один знак в шаблоне не давали двойного процента.

В upstream beta10 `common.percent` уже равен `%1`, а `percentage()` получает
`percentArgument()`, который возвращает число **со знаком** из QLocale.
Первый контроль ошибочно перенёс fork RU `%1%` — паритет `%N` этого не обнаружил.
Это подтверждённая несовместимость переноса строки, не ошибка батареи/Qt renderer.

Минимальная правка для beta10: RU `common.percent` = `%1`, как EN.
Formatter и battery drawing остаются upstream. Не заявляем неизвестный старый
commit с «тем же исправлением»: прежняя fork схема имела другой контракт.
Добавлена отдельная проверка точного значения EN/RU шаблона в
`platforms/control-beta10/validate.cmake`; обычной проверки placeholders мало.
Правка распространяется на все потребители percentage(), а не маскирует батарею.

## Шрифты — approved scope, blocked inputs

Разрешены пользователем только для русского:

1. MTCORSVA вместо Instrument Serif.
2. Caveat вместо Kalam по умолчанию.

**Не применено**: файлы с такими именами/семействами в указанной папке отсутствуют.
На момент осмотра там три TTF: Adventure, Oranienbaum-Regular, ViaodaLibre-Regular.
В текущем сообщении приложен только PNG. Эти три гарнитуры самовольно не подменяем.
Нужны сами MTCORSVA/Caveat, их точные начертания и информация о праве включения
в распространяемый пакет. Для MTCORSVA особенно важно не считать разрешение
использования системного шрифта разрешением на его перераспространение.

До получения файлов неизменны font assets/manifest, шрифтовая регистрация,
private renderer и English font selection. После получения следует проверить
family/style names, кириллицу/ё/й, регистрацию Qt5 и переключение только RU
как в Qt font selection, так и в private renderer. English остаётся upstream.

## Проверки

Локально: strings generation/rebuild; production references; key/slot parity;
точное значение common.percent; проверка набора изменённых файлов и SHA-256;
bash syntax и diff whitespace. Отрицательная проверка: прежний `%1%` обязан
провалить новый guard. Qt5 compile/package — отдельный CI текущего patch.
Raster/скриншот после исправления и физическая проверка не выполнены.
Первый CI45212880701 не является проверкой нового ink-box patch.

Локальный нюанс harness: при Unix Makefiles self-test reconfigure дважды не
увидел изменение файла в тот же timestamp tick; с Ninja прошёл. CI harness
явно выбирает Ninja, как и основной Qt5 preset. Upstream self-test/runtime
из-за этого не менялись. Отрицательный guard со старым %1% завершился ожидаемой
ошибкой. Это не raster-проверка исправления подписи.
