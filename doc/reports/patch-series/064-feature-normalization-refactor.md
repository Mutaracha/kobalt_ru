# R07 — таблица сброса зависимых параметров скрытых функций

Статус: implemented; local series PASS; CI/device pending.
R06 на b390fefa пользователь проверил и разрешил продолжать. База R07 — 06a713f0
(runtime b390fefa). Приёмка R06 не распространяется автоматически на R07.

## Область

В reading/features.h шесть независимых удалений параметров объединены в
ResetRule table: navigation_bar_buttons, dense_stats_chart, stats_word_scope,
minimal_annotation_mode, annotation_interaction, save_looked_up_words.
Ранее они были распределены по отдельным if-блокам.

Очистка не-bool flags, fallback стартового меню, условие совместного marks_sort
и особая зависимость Activity от Stats не менялись. Reset table содержит только
зависимые параметры, не сами feature flags, поэтому порядок независимых remove
не влияет на результат. Формат профиля, id/порядок/ключи 10 функций и default enabled
не меняются; новых пунктов UI нет. Это не расширение scope скрываемых функций.

## Проверки

В model.appearance-settings добавлен независимый frozen reference старого
алгоритма с буквальными ключами. Для всех 1024 комбинаций десяти bool-флагов
и трёх вариантов меню (none/seek/stats) сравнивается полный JSON-результат:
3072 сценария, плюс отсутствие настроек и malformed flags. Проверяется также
идемпотентность и сохранность nested unknown option. Production reset table
и production enabled() не используются reference-алгоритмом.
Прежние отдельные тесты Activity/Stats, shared sort и cleaning сохранены.

Только 040: один production header и существующий native test. Остальные 1550
пути/байты/режимы не меняются. Reference amendment хранит предыдущие хеши.
Вся серия 1552 файлов применяется; 15 локальных Python series/package/equivalence
regressions PASS. Qt/cmake SDK отсутствует локально; C++ cases требуют CI.
Кэш, font registration, перевод, Letter, навигационные жесты не менялись.

## Устройство после CI

1. Открыть «Скрыть ненужные функции»: список и текущие переключатели прежние.
2. Скрыть/вернуть кнопку тёмной темы и комиксов; проверить меню, не меняя сам режим.
3. Закрыть Kobalt, вручную открыть книгу: текущие переключатели сохранены,
   выбранное оформление/позиция книги не сброшены.

Не нужно скрывать все функции разом: как и прежде, скрытие навигации/статистики/
аннотаций/слов сбрасывает некоторые их зависимые параметры. Эту матрицу проверяет
native regression; ради неё не требуется менять пользовательский профиль на устройстве.
