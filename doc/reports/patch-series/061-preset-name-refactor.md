# R04 — граница строкового слоя для имён встроенных стилей

Статус: implemented; local series PASS; CI/device pending.
R03 на 2ffacc74 пользователь проверил и разрешил продолжать. Его приёмка не
распространяется автоматически на этот этап. База — e1282aab (runtime 2ffacc74).

## Изменение

fork_text_preset_names.h ранее напрямую вызывал strings::detail::find и
strings::detail::russianTable. Он знал устройство обеих таблиц переводов,
хотя должен решать только вопрос представления сохранённого имени стиля.

Распознавание точного EN/RU значения вынесено в strings::matchesTranslation.
Helper не меняет locale, не включает/выключает key mode, не использует fallback
«неизвестный ключ возвращает себя» как перевод и не меняет get()/entries().
Имя сравнивается с теми же двумя записями, в том же порядке, как до выделения.

У displayName остаются все прежние условия: example=true, известный id одного
из четырёх shipped стилей и сохранённое имя в точности соответствует EN или RU
варианту. Только тогда возвращается get(key). Пользовательские, переименованные
и неизвестные стили не переводятся. Прямой доступ к detail из этого потребителя
устранён; политики видимости, применения и записи стилей не изменены.

## Проверки

Расширен существующий fork-presentation native target: все 4 id и их независимо
заданные EN/RU имена, каждый активный язык, key mode on/off, сохранность всех
полей preset (включая изменённый font/size), user example=false, неизвестный id,
пустые/свои/иначе написанные имена, регистр/конечный пробел, отсутствующий ключ,
неизменность locale/key mode. Ожидаемые значения не берутся из production matcher.
В key mode подпись распознанного стиля по-прежнему равна get(key), а не обычному
переводу: это сохранённое поведение диагностики.

Из runtime меняются только 3 прежних пути: support/strings.h (010),
reading/fork_text_preset_names.h и tests/model/fork_presentation.cpp (050).
Нет новых файлов, новых патчей, схем данных или изменений RU/EN каталогов.
Reference-tree содержит прежние хеши этих файлов как explicit amendment.
Остальные 1549 путей/байтов/режимов совпадают; полная серия из 1552 файлов применяется.
Все 15 локальных Python series/package/equivalence regressions PASS. Новый C++ тест
локально не запускался: Qt/cmake SDK отсутствует. CI/native/Qt5/package ещё требуется.

## Устройство после CI

1. Открыть «Текст» и проверить названия встроенных стилей и применение одного из них.
2. Если есть свой/переименованный стиль, проверить, что имя и настройки не изменились.
3. Переоткрыть книгу: выбранный шрифт/размер и стили не сбросились.
4. По возможности переключить интерфейс RU→EN→RU штатным способом с перезапуском:
   встроенные названия следуют языку, свои названия остаются прежними.

Не требуется сбрасывать стили, профиль или создавать новый пользовательский стиль.
Кэш, Hybrid, Letter, файлы шрифтов и touch/button navigation не менялись.
