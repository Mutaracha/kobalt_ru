# Первый этап рефакторинга кода: оформление fork toolbar actions

Статус: **done; CI PASS; device accepted**. Пользователь разрешил разбор и
рефакторинг кода после консолидации и готов проверить новую сборку на устройстве.
Это расширяет прежний scope «консолидация без изменения runtime-кода»; семь слоёв
по-прежнему применяются вместе в прежнем порядке.

## База и решение

База до рефакторинга: `b753ef286b55d4b30d4b7d8e7c3191ac6f57606b`, с обеими
принятыми итерациями перевода. Она остаётся воспроизводимой через Git.
Не смешивать её CI с CI нового исходного кода.

В 050 `Navigation::styleForkToolbarActions` и `restoreForkToolbarActions`
содержали два одинаковых блока — для darkTheme и comics. Вынесены общие
`forkui::styleToolbarAction` / `restoreToolbarAction` в существующие
fork_navigation.cpp/.h. Каждый вызов получает собственные savedStyle/savedPaint,
без нового глобального состояния, новой зависимости или нового слоя патчей.

Сохранены порядок действий, null guards, dynamic_cast для ui::Button,
ToolbarCell при входе и прежний paint mode при выходе. Размер при выходе,
как и раньше, берётся из toolbarButtonSize, а не из произвольного снимка размера.
Состояния checked/enabled, действия, видимость, callbacks и владение кнопками
не меняются. Кнопки настроек/поиска/синхронизации upstream пока не включены в
этот helper: первая итерация ограничена fork-кодом с одинаковым контрактом.

## Проверки и доказательства

- Изменён только 050 и его checksum, не 010 и не перевод.
- Три изменённых runtime-пути: два файла fork_navigation и существующий
  tests/model/fork_presentation.cpp. Остальные 1548 пути/байты/режимы неизменны.
- reference-tree содержит явное approved amendment с прежними хешами трёх файлов.
  Проверка равенства фиксирует границы изменений, но не доказывает семантическую
  эквивалентность отрефакторенного кода.
- Добавлен native regression в уже собираемый/запускаемый CI target
  kobalt-fork-presentation-tests: два ui::Button с разными paint modes,
  обычный QPushButton, отсутствующая кнопка, три цикла style/restore,
  сохранение stylesheet, геометрии и checked/enabled.
- Все 15 локальных Python series/package/equivalence regressions PASS, полная
  серия применяется. Локально нет Qt/cmake SDK: новый C++ тест ещё не запускался;
  запуск обеспечивается существующим selected native CI.
- Кэш, FB2/Hybrid, системные шрифты, схема данных и сохранение позиции не изменены.

## Минимальная проверка устройства после успешного CI

1. Открыть привычную книгу вручную. Открыть и закрыть меню чтения несколько раз.
2. Переключить обычный вид меню → «Навигация» → обычный вид, повторить 3 раза.
   Проверить размер/значки кнопок тёмной темы и комиксов: без залипания стиля.
3. В светлом и тёмном режиме повторить переходы; проверить работу переключателя
   тёмной темы и сохранение выбранной темы.
4. Включить/выключить комиксы, повторить переходы: значок соответствует режиму,
   поля и колонтитулы возвращаются при выключении комиксов.
5. Скрыть эти функции через настройки и вернуть: кнопки не появляются самовольно.
6. Сон/пробуждение и повторное открытие книги: нет нового зависания или потери позиции.

Не требуется новый тайминг-бенчмарк. При отклонении указать режим меню, тему,
состояние comics и шаг воспроизведения; снимок экрана будет полезнее средней скорости.
Следующий этап выбирается после CI и этой проверки, не автоматически.
