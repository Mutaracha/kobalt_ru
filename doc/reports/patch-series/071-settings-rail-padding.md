# Более узкие вкладки настроек

По просьбе пользователя (скриншоты EN/RU) уменьшены горизонтальные внутренние
отступы боковых вкладок Settings. Было round(railInset * .8), стало
round(railInset * .5): при базовом railInset=28 это 22 → 14 единиц с каждой стороны.
Отступы не убраны. Размер шрифта, иконки, высота строк, текст перевода и рамки
не меняются. Ширина по-прежнему вычисляется по самому длинному видимому названию,
поэтому RU/EN не получают фиксированную ширину с риском обрезки текста.

Обе величины (QSS padding и fitRail width) изменены согласованно. Список
на узких экранах сохраняет прежний chrome::inset; меняется только боковая панель.
Изменения включены в основной 040; hash и reference amendment обновлены.

Локальные проверки: все 15 series/package/equivalence tests PASS;
1552 runtime files identical. Нативная сборка и тесты PASS:
https://github.com/Mutaracha/kobalt_ru/actions/runs/45963000261 .
Пользователь подтвердил: «интерфейс проверил, выглядит хорошо».
Статус: accepted. Новая установка для docs-only cleanup не нужна.
