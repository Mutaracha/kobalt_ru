# Beta9 → beta10: предложения перевода

**Статус: для согласования. Runtime, активные патчи и установленный перевод не изменены.**

Сравнение английских каталогов: **186 новых**, **50 изменённых**, **10 удалённых** ключей. Всего 236 строк дельты: **8 уже согласованы**, **228 предлагаются к рассмотрению**. Ещё 5 строк Letter вынесены отдельно, так как не менялись upstream.

## Источники и границы

- Beta9: `be47258850ffdc3295257475afdf8b8f6cb53176` (manifest v1.0-beta.9); beta10: `1796a32559dbb2912bd565990d1c7a0ca7ac4e52`.
- Сравнение по ключу и декодированному EN-значению, не по позиции строки или разнице RU-файлов. Изменения только регистра тоже показаны.
- Текущий RU извлечён из активного консолидированного010. Тестовый перевод ветки83c6bb75 не считается автоматически согласованным только потому, что уже существует.
- Зафиксированные уточнения из translation-review текущей ветки и последующие изменения относительно начального control-overlay сохранены. Их полный список есть в delta.json/preserved. Согласованные строки в предложения повторно не включены.
- Одинаковая предлагаемая и текущая RU-строка означает «проверено по EN, предлагается сохранить», а не «уже согласовано».
- Образцы экрана Письмо: новая просьба пользователя имеет приоритет над прежней конструкцией. Ранее согласованное «Осталось читать примерно %1.» не меняется.
- [Машинная дельта](delta.json), [частичный фрагмент предложений](proposed-ru.strings). Фрагмент не является полным каталогом и не предназначен для установки.

## Существенные смысловые места

- У полного сброса настроек изменена область действия; старый RU это не отражал.
- У Hybrid добавлено описание поведения после полной подготовки книги.
- «Системные шрифты» и «Коллекция Kobalt» — разные источники, не синонимы.
- `Button 1/2` заменили `Upper/Lower`: предложены «Кнопка 1/2».
- Сохранены все %1/%2/%3 с тем же количеством вхождений. Значения процентов уже форматируются вызывающим кодом; двойной % не добавлен.
