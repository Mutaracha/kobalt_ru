# Uploaded font samples

- `Shantell Sans/`: supplied static faces, originals unchanged; runtime uses Italic+Bold Italic only.
- `Noto Serif Display Condensed/`: supplied static faces; runtime uses Regular+Italic only.
- `Kobo/fonts/`: supplied device inventory used by archived-source CI replay; not newly bundled UI fonts.
- `legacy/monotype-corsiva.zip`: original historical sample, not included in runtime.

Historical fonts attached to old diagnostic archives stay in `../archive/`; do not
rewrite their provenance or bundle them. File hashes are in ../catalog.json and ../SHA256SUMS.

- `Literata/`: six supplied static faces and OFL; Regular/Italic/Bold/BoldItalic now bundled for RU reading roles.

- `Lora/`: six supplied static faces and OFL; four corresponding standard styles bundled for RU Bookish.
