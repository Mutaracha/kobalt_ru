# User-supplied stock beta.8 baseline

Source: seven screenshots attached by the user when authorizing the beta.8
migration. Described by the user as stock beta.8; exact binary/source SHA and
book bytes were not supplied, so these are visual references, not pixel tests.
Files are unmodified; verify with `sha256sum -c SHA256SUMS` in this directory.

- screen_001-10.png: physical button assignments.
- screen_002-7.png: hidden-features dialog.
- screen_003-5.png: System settings, privacy/sleep and hidden features.
- screen_004-3.png through screen_007.png: EPUB inline footnotes, including a
  smaller body font. A substantial body-to-note gap remains in stock beta.8.
  Copying the upstream mechanism does not resolve the fork's gap requirement.

The request also confirms the preceding comics and Libra 2 rotation fixes.
