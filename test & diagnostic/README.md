# Поддерживаемые тестовые данные

Старые диагностические uploads удалены из текущего дерева по решению пользователя:
исправления приняты, проблема кэша больше не повторяется. Исторические материалы
доступны в Git на `40ec2610` и более ранних коммитах; ссылки из старых отчётов
относятся к тому состоянию дерева, а не к текущим незакрытым задачам.

Оставлен `FB2-034-test-inputs.zip` без изменения байтов. Workflow
`.github/workflows/patch-series.yml` извлекает из него `034-2-ACCURATE.fb2`
для реального регрессионного теста Layout/comics preview. Это тестовый вход,
а не диагностический отчёт и не часть установочного пакета.

Проверка из корня: `sha256sum -c 'test & diagnostic/SHA256SUMS'`.
Новые логи добавлять только для конкретного воспроизводимого дефекта,
предварительно проверив персональные данные. Подробнее:
[закрытие текущего цикла](../doc/reports/patch-series/072-cleanup-and-navigation-audit.md).
