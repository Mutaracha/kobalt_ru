# Архив beta9 и старше

Диагностика beta7–9, связанные screenshots/books/font inputs и beta5 evaluation
runs. Исторические данные, не входы приёмки текущей beta10 и не открытая очередь.
Архивы, изображения, книги и шрифты перенесены побайтно. Старые README отражают
контекст того времени, не текущее состояние. Manifest: doc/archive/material-moves.json.

Классификация: startup.version/source_commit в ZIP/context; связанные материалы
группируются с соответствующим runtime. `reading-menu-counter` относится к удалённому
fork UI. `evaluation` содержит beta5 по заголовкам JSONL.
Смешанный `08c66e4d` с beta9 и beta10 оставлен в действующем каталоге без разрезания.
