# Ручные тестовые материалы

Старые интерфейсные снимки и review-отчёты удалены по указанию пользователя.
Материалы прежних билдов, оставшиеся в репозитории, перенесены в
`test & diagnostic/archive/pre-beta10/`; удалённые ранее оригиналы доступны в истории Git. Сохранены исходные пользовательские книги,
не являющиеся portable CI fixtures. Их байты не изменены.

Книга `books/publisher/Кокаиновые+короли.epub` используется только для opt-in
проверки `tests/model/links.cpp --publisher-notes PATH`; не распространяется
как новая общая fixture. Контрольные суммы: `materials.sha256`.
Проверка из корня: `sha256sum -c tests/manual/materials.sha256`.
