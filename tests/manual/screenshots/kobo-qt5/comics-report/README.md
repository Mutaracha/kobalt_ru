# Пользовательское сравнение CoolReader / Kobalt / Nickel

Исходные вложения пользователя сохранены побайтно, с нейтральными именами:

| Файл | Оригинальное имя | Контекст по сообщению пользователя |
|---|---|---|
| coolreader.png | cr.png | CoolReader из пакета Vlasovsoft; пример отметок глав в верхней полосе |
| kobalt.png | kobalt.png | Манга, остаточная нижняя белая полоса |
| nickel.png | nickel.png | Та же страница в системной читалке, без нижней полосы |

Бинарный SHA Kobalt, точная версия CoolReader и файл книги пока не установлены.
Не приписывать снимки автоматически последнему CI-билду. Имя книги на preview
не доказывает формат файла или идентичность CSS/исходного ресурса в ридерах.
Не считать пример из другой читалки результатом изменения Kobalt.

SHA256SUMS проверяется из корня репозитория. PNG не перекодировались.
