| Файл | Оригинальное имя | Контекст по сообщению пользователя |

| kobalt.png | kobalt.png | Манга, остаточная нижняя белая полоса |

Пользователь уточнил: Kobalt build 94, commit d7b7d55. Точная версия CoolReader
в cr.png не установлена. Пример книги добавлен в doc/Spice and Wolf v01.kepub.epub/
коммитом ad349b7; это unpacked страница с исходными XHTML/CSS/PNG, но OPF
сохраняет ссылки на удалённые ресурсы. Не приписывать снимки последующим CI-билдам. Имя книги на preview
не доказывает формат файла или идентичность CSS/исходного ресурса в ридерах.
Не считать пример из другой читалки результатом изменения Kobalt.
