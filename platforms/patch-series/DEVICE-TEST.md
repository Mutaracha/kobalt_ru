# Полная ordered series 010–060 — Kobo Qt5 hardware test

Использовать только **Kobalt-ru-beta10-series-qt5** из workflow **Ordered patch series**.
В Actions artifact находится установочный `Kobalt-ru-beta10-series-qt5.zip`.
Это вся согласованная серия поверх pristine beta10; аппаратная приёмка ещё
не выполнена. Не использовать старый `Kobalt-qt5-device` или прежние prefix
artifacts. Старый legacy workflow отключён.

1. Сохранить backup `.adds/kobalt` и пакет для отката. Устройство: Kobo Qt5,
   firmware 4.38+; не Qt6/Android. Не тестировать единственную копию аннотаций.
2. Распаковать внешний Actions artifact на компьютере. Проверить SHA256SUMS
   (`sha256sum -c SHA256SUMS`, либо совместимой утилитой). Сохранить source-commit.txt.
3. Распаковать **внутренний установочный ZIP** в корень подключённого Kobo:
   должны появиться `.kobo/KoboRoot.tgz`, `.adds/kobalt/assets/` и
   `.adds/kobalt/series-provenance.json`. Не копировать внешний artifact целиком.
4. Безопасно извлечь Kobo, дождаться установки и перезапуска. Открыть обычный
   EPUB, затем raw FB2. Первый критерий: действительно открылся Kobalt, а не Nickel.
5. Сверить About commit с первыми семью символами source-commit.txt. Затем
   проверить comics, кеш повторного открытия, язык Debug и presentation по спискам ниже.

`series-provenance.json` содержит исходный commit, upstream pin и порядок/SHA256
всех патчей; его копия устанавливается на устройство. `installed-library.sha256`
даёт SHA256 распакованной ARM library для диагностики установки. CI проверяет
ELF32 ARM, единственный ожидаемый путь в KoboRoot.tgz, mode0755/owner0:0,
совпадение установленного provenance и внешние checksums. Это проверки упаковки,
не доказательство запуска на реальном Kobo.

Если вместо Kobalt открылся Nickel: остановить дальнейшие функциональные
проверки; прислать source-commit.txt, модель/firmware, установленный
`.adds/kobalt/series-provenance.json` и доступные startup/crash diagnostics.
Не сбрасывать профиль/markers и не удалять логи перед сбором информации.

## Какой пакет выбирать

В Actions → **Ordered patch series** → успешный прогон нужного коммита →
артефакт **Beta10-series-prefix-qt5**. Распаковать скачанный Actions artifact;
внутри находится установочный `Beta10-series-prefix-qt5.zip` и provenance.

Не использовать `Kobalt-qt5-device` из другого workflow для приёмки переноса:
он пока собирает legacy checkout. Зелёный workflow сам по себе не доказывает,
что установлен пакет именно из beta10 export.

## Установка и проверки

Только Kobo Qt5 (firmware 4.38+), не Qt6/Android. Это экспериментальная сборка:
сохраните резервную копию `.adds/kobalt` и привычный установочный пакет для отката.
Не проверяйте единственную копию важных аннотаций/позиций без backup.

Распаковать внутренний установочный ZIP в корень подключённого Kobo так, чтобы
`.kobo/KoboRoot.tgz` и `.adds/kobalt/assets` оказались на своих местах. Безопасно
извлечь устройство и дождаться установки/перезапуска. Не устанавливать одновременно
другой Kobalt-пакет. При смене пакета не копировать конфигурацию поверх backup вслепую.

Проверить:
- открытие обычного `.fb2` из системной библиотеки, UTF-8 и Windows-1251;
- заголовок/автор, обложку, оглавление, изображения, стихи и таблицы;
- переход по сноске и назад, переключение встроенных примечаний;
- изменение шрифта/размера/ориентации и сохранение позиции;
- закрытие/повторное открытие и сон/пробуждение;
- обычный EPUB после FB2 и FB2 после EPUB.

FB2.ZIP не входит в объём работ: системная библиотека его не показывает.
Смешанный Russian_EnUS.pattern не включён, обычный Russian.pattern сохранён.
Не трактовать этот тест как приёмку всего форка или исправление Hybrid.

При ошибке указать commit из source-commit.txt, модель/firmware, точный сценарий,
исходный формат/кодировку и приложить книгу (если допустимо) и диагностический лог.

Дополнительно для комиксов: включить режим в Layout, проверить portrait/landscape,
пары портретных страниц и одиночные развороты, RTL (при наличии книги), повторное
открытие/сон, затем выключить режим и проверить восстановление полей и колонтитулов.
Для пакета 010–040 кнопки тёмной темы и комиксов уже добавлены в меню чтения.
Проверить синхронизацию с Display/Layout, сохранение режима после повторного
открытия, скрытие кнопок в Settings и Zen, независимое скрытие через Features.
После выключения комиксов должны вернуться прежние поля/колонтитулы.
Проверить отказ/восстановление состояния при занятом рендеринге и превью Layout.
Инверсия свайпов остаётся штатной beta10: проверить отдельно от физических
кнопок, включая RTL; второго переключателя инверсии быть не должно.
