# Beta10 series prefix — тестовый пакет для устройства

**Это не полный форк и не старый артефакт `Kobalt-qt5-device`.**

Пакет собран workflow `Ordered patch series` из pristine upstream beta10 с
последовательно применённым подготовленным началом серии. Точный список,
статусы и SHA256 патчей находятся в `applied-prefix.json`; там же перечислены
ещё не включённые этапы. Коммит управляющего репозитория — `source-commit.txt`.
`SHA256SUMS` проверяет внешний установочный ZIP.

Первый успешно опубликованный пакет — коммит 08c66e4d, CI 45278312375:
010 + 020 + 021 + 022 + 023 + 030 + 031 + 032 (RU, raw FB2 и comics).
Режим комиксов доступен в Layout. Toolbar/остальные доработки ещё не перенесены.
Последующие прогоны могут включать следующие патчи: сверяйте applied-prefix.json.

## Какой пакет выбирать

В Actions → **Ordered patch series** → успешный прогон нужного коммита →
артефакт **Beta10-series-prefix-qt5**. Распаковать скачанный Actions artifact;
внутри находится установочный `Beta10-series-prefix-qt5.zip` и provenance.

Не использовать `Kobalt-qt5-device` из другого workflow для приёмки переноса:
он пока собирает legacy checkout. Зелёный workflow сам по себе не доказывает,
что установлен пакет именно из beta10 export.

## Установка и проверки

Только Kobo Qt5 (firmware 4.38+), не Qt6/Android. Это экспериментальная сборка:
сохраните резервную копию `.adds/kobalt` и привычный установочный пакет для отката.
Не проверяйте единственную копию важных аннотаций/позиций без backup.

Распаковать внутренний установочный ZIP в корень подключённого Kobo так, чтобы
`.kobo/KoboRoot.tgz` и `.adds/kobalt/assets` оказались на своих местах. Безопасно
извлечь устройство и дождаться установки/перезапуска. Не устанавливать одновременно
другой Kobalt-пакет. При смене пакета не копировать конфигурацию поверх backup вслепую.

Проверить:
- открытие обычного `.fb2` из системной библиотеки, UTF-8 и Windows-1251;
- заголовок/автор, обложку, оглавление, изображения, стихи и таблицы;
- переход по сноске и назад, переключение встроенных примечаний;
- изменение шрифта/размера/ориентации и сохранение позиции;
- закрытие/повторное открытие и сон/пробуждение;
- обычный EPUB после FB2 и FB2 после EPUB.

FB2.ZIP не входит в объём работ: системная библиотека его не показывает.
Смешанный Russian_EnUS.pattern не включён, обычный Russian.pattern сохранён.
Не трактовать этот тест как приёмку всего форка или исправление Hybrid.

При ошибке указать commit из source-commit.txt, модель/firmware, точный сценарий,
исходный формат/кодировку и приложить книгу (если допустимо) и диагностический лог.

Дополнительно для комиксов: включить режим в Layout, проверить portrait/landscape,
пары портретных страниц и одиночные развороты, RTL (при наличии книги), повторное
открытие/сон, затем выключить режим и проверить восстановление полей и колонтитулов.
Не ожидать comics/dark кнопок toolbar: это следующий 040.
